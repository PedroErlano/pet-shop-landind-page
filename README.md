#  Pata Feliz — Pet Shop

Uma landing page responsiva para um pet shop, desenvolvida com HTML, CSS e JavaScript puro.

 **[Acessar o site](https://patafelizpet.netlify.app/)**

##  Sobre o projeto

A Pata Feliz é um projeto demonstrativo de desenvolvimento web criado para apresentar os serviços de um pet shop de forma visualmente atrativa, organizada e acessível.

O projeto busca oferecer uma experiência intuitiva aos visitantes, facilitando a consulta de serviços e o contato com o estabelecimento.

##  Funcionalidades

-  Apresentação do pet shop e de seus serviços.
-  Galeria de imagens.
-  Acesso ao contato pelo WhatsApp.
-  Opção de agendamento de serviços.
-  Interface responsiva para diferentes dispositivos.

##  Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilização e layout responsivo.
- **JavaScript:** interatividade da interface.

O projeto foi desenvolvido sem frameworks ou bibliotecas JavaScript.

##  Como executar localmente

### Pré-requisitos

- Git instalado.
- Um navegador web moderno.

### Instalação

Clone o repositório:

```bash
git clone https://github.com/PedroErlano/pet-shop-landind-page.git
```

Entre na pasta do projeto:

```bash
cd pet-shop-landind-page
```

Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou executar um processo de build para a versão estática do projeto.

##  Deploy

O site está hospedado no Netlify.
